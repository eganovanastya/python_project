# python_project
1. Изучить
  выбрать инструменты для реализации Фронтенда, бэкенда(ПИТОН), бд.


2. Бэкенд

  1.Управление комнатами: Создание комнаты с генерацией уникальных кодов для входа.
  2. Синхронизация в реальном времени: Передача событий (старт игры, смена вопроса и тп.) от организатора ко всем участникам одновременно.
  3.Обработка подключений: Отслеживание того, кто зашел в комнату, кто отключился, и нельзя дублировать имена.
  4.Логика: Проверка ответов на правильность, начисление баллов, учет таймера и возможность ответить на вопрос только один раз.
  5.Хранение состояния: Ведение текущего счета всех игроков(таблица), номер вопросов и статуса игры (ожидание, в процессе, завершена).



3. Фронтенд

	1. Интерфейс Организатора:
	     Экран создания игры (кнопка «Создать» и показ кода комнаты).
	     «Лобби»: изменяющийся список подключившихся участников.
	     Панель управления: кнопки запуска игры и перехода к следующему вопросу.
	     Экран статистики: отображение того, как участники отвечают на текущий вопрос в реальном времени.(?)

	2. Интерфейс Участника:
	  Экран входа: поля для ввода имени и кода комнаты.
	  Экран ожидания.
	  Экран вопроса: текст вопроса, кнопки с вариантами ответов и таймер.
	  Экран результата: отображение правильного ответа, начисленных баллов и текущего места в рейтинге.
